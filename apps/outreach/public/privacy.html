Privacy Policy

Last updated: July 2026

Builder.LI ("we", "our") operates a Chrome extension and web application that helps teams score LinkedIn profiles against their Ideal Customer Profile (ICP) and draft personalized connection notes. This policy explains what data we collect, why, and how it is handled.

What data the extension collects

When you visit a LinkedIn profile page and click "Draft note", the extension reads the following fields from the page you are already viewing:

  • Name, headline, current role, and company
  • About section text
  • Recent activity visible on the profile
  • Profile URL

The extension reads only the profile you explicitly open, on a manual click, one profile at a time. It does not browse LinkedIn automatically, access your connections, messages, feed, or any other part of LinkedIn.

How that data is used

The profile fields are sent to your team's Builder.LI workspace (hosted on Netlify) where they are:

  • Scored against your team's uploaded ICP document
  • Used to generate a personalized connection note draft
  • Stored in your workspace database so you can review past drafts

Profile data is never sold, shared with third parties, or used for advertising.

Authentication data

The extension stores a personal API token in Chrome's local extension storage (chrome.storage.local). This token links extension requests to your Builder.LI account. It is never transmitted to any service other than your own Builder.LI workspace.

Data storage and retention

Profile drafts are stored in your workspace's Postgres database on Neon (neon.tech). Data is retained until you delete it or close your workspace. Builder.LI does not access your workspace data.

Permissions used

  • activeTab / scripting — reads the LinkedIn profile page you are currently viewing when you click the extension icon
  • storage — stores your API token locally in Chrome
  • sidePanel — displays the draft panel alongside the LinkedIn page
  • https://www.linkedin.com/* — required to read the profile page content
  • https://builder-li.netlify.app/* — sends profile data to your workspace and retrieves the generated draft

Changes to this policy

We may update this policy as the product evolves. Material changes will be noted in the extension's changelog.
